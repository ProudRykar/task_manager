# Task Manager с использованием Tkinter и Psutil

Это приложение Python представляет собой простой **Task Manager**, построенный с использованием **Tkinter** для интерфейса и **psutil** для получения информации о процессах и системе. Оно позволяет просматривать и управлять системными процессами, сортировать их по различным параметрам, искать процессы, а также получать подробную информацию о процессе в реальном времени.

## Функции:
- **Список процессов**: Отображает все запущенные процессы с такими деталями, как PID, имя, использование CPU, использование памяти и статус.
- **Сортировка**: Возможность сортировки процессов по PID, имени, использованию CPU, использованию памяти или статусу в порядке возрастания или убывания.
- **Поиск**: Поиск процессов по PID или имени, фильтрация по состояниям (например, `/idle`, `/running`, `/sleeping`, `/zombie`, `/stopped`), а также поиск процессов, использующих открытые порты.
- **Подробная информация о процессе**: Просмотр подробной информации о выбранном процессе, включая использование CPU, памяти, статус и открытые порты (если они есть).
- **Интеграция с буфером обмена**: Возможность копировать PID процесса в буфер обмена для удобного доступа.
- **Обновления в реальном времени**: Непрерывное обновление информации о процессе (CPU, память, статус) в реальном времени при открытом окне с деталями процесса.

## Требования:
- Python 3.x
- Tkinter
- Psutil
- Pyperclip

## Компоненты:

### 1. **Treeview**:
   - Структура, похожая на таблицу, для отображения процессов с колонками, такими как `PID`, `Name`, `CPU %`, `Memory` и `Status`.
   - Каждая строка представляет собой процесс, и вы можете сортировать строки по щелчку на заголовках колонок.

### 2. **Поиск**:
   - Панель поиска внизу позволяет фильтровать процессы по PID или имени.
   - Вы также можете фильтровать процессы по состояниям, таким как `/idle`, `/running`, `/sleeping`, `/zombie`, `/stopped`, или найти процессы, использующие открытые порты.
   - Поиск по портам реализован с помощью команды `:ports` или с указанием конкретного порта в формате `:{число}`.

### 3. **Информация о процессе**:
   - При щелчке по процессу в `Treeview` открывается раздел с подробной информацией о процессе, которая включает:
     - PID
     - Имя
     - Использование CPU
     - Использование памяти
     - Статус процесса
     - Открытый порт (если есть)
   - PID можно скопировать в буфер обмена с помощью кнопки "Copy".

### 4. **Обновления в реальном времени**:
   - Когда процесс выбран для отображения подробной информации, приложение будет показывать обновления использования CPU, памяти и статуса процесса в реальном времени.

### 5. **Возврат к списку процессов**:
   - Кнопка "Back" в разделе с подробной информацией позволяет вернуться к основному списку процессов.
